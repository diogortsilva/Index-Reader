Windows program, built automatically from this revision of the source code.

**To use it**

1. Download `Index-Reader-vX.Y.Z-windows.zip` from the Assets below.
2. Right-click the zip, choose **Extract All...**, and extract it to a folder you can write to (Documents or Desktop).
3. Open the extracted `Index-Reader` folder and double-click **Index-Reader.exe**.

No Python, no installation, no internet connection and no other software is needed. The program is not code-signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.

Results are saved in `Projects\<date>_<time>_<index file name>\` next to `Index-Reader.exe`.

See `CHANGELOG.md` for what changed in each version.
